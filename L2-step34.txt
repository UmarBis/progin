Шаг 3 и 4:
переходим к созданию самих Workflow



Создаем CI (Проверка кода):
cd catty-reminders-app
mkdir -p .github/workflows
nano .github/workflows/ci.yml


КОД:
name: CI

on:
  push:
    branches:
      - lab2
      - lab2_autotests*
  pull_request:
    branches:
      - lab2
      - lab2_autotests*

jobs:
  pipeline:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python 3.12
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt
          pip install uvicorn pytest-playwright
          playwright install --with-deps chromium

      - name: Start app
        run: |
          nohup uvicorn app.main:app --host 127.0.0.1 --port 8181 &
          sleep 5

      - name: Run tests
        env:
          PYTHONPATH: ${{ github.workspace }}
        # Генерируем XML отчет для бота
        run: pytest --junitxml=test_result.xml || true

      - name: Upload test results
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: test_result
          path: test_result.xml # Файл будет в корне архива


Создаем CD (Деплой на виртуалку):
nano .github/workflows/deploy.yml


КОД:
name: Deploy
on:
  release:
    types: [published]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Deploy via script
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: course.prafdin.ru
          username: ilya
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          port: 3120
          # Вызываем скрипт и передаем SHA коммита
          script: bash ~/catty-reminders-app/run_app.sh ${{ github.sha }}
